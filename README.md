# 길잡이 — 아이폰용 내비게이션 (PWA)

출발지와 도착지만 넣으면 **도보 · 버스 · 자동차 · 자전거** 최적 경로를 잡아 주고,
**2D 평면 지도**와 **3인칭 3D 지도**로 안내하는 웹앱입니다.
아이폰 사파리에서 "홈 화면에 추가"하면 주소창 없는 전체화면 앱으로 뜹니다.

## 무엇이 되나

- **출발지 칸을 누르면 메뉴**가 열리고, 첫 항목이 `현재 내 위치로 설정하기` — 누르면 GPS 로 잡은
  지금 위치가 역지오코딩되어 출발지로 들어갑니다. 아래로 최근에 찾은 곳과 검색 결과가 이어집니다.
- **도착지는 그냥 씁니다.** "창원 NC 파크 동문" 처럼 치면 후보가 뜨고, 안 고르고 `경로 찾기` 를
  눌러도 가장 유력한 곳으로 알아서 잡습니다.
- **도보 / 자전거 / 자동차** — 실제 도로망 기준 최적 경로 + 한국어 turn-by-turn 안내.
  도보·자전거는 **경사도에 따라 경로선 색이 바뀌고**, 아래에 오르막·내리막 고도 프로필이 붙습니다.
- **버스** — 실제 시각표로 계산한 단계별 안내.
  1. 출발지에서 가장 가까운 정류장까지 걷는 길
  2. **몇 번 버스를 어디서 타는지** (방면, 지나는 정거장 수, 출발 시각)
  3. **어디서 내리는지** — 환승이 필요하면 내릴 정류장과 갈아탈 정류장, 그 사이 도보까지
  4. 마지막 정류장에서 도착지까지 걷는 길

  `단계별 안내 시작` 을 누르면 GPS 를 따라가며 **정류장에 도착하면 다음 단계로**,
  **버스에 타면 승차 단계로**, **내릴 정류장에 가까워지면 알림**, **내리면 다음 단계로** 넘어갑니다.
  수동으로 "탔어요 / 내렸어요" 를 눌러 넘길 수도 있습니다.

- **지도 2D / 3D**
  - **2D** — 평면. 땅과 길은 살짝 진한 회색, 건물은 그보다 더 진한 회색. 전 세계 실제 건물 윤곽과
    도로망을 벡터 타일로 그립니다.
  - **3D** — 같은 색으로 건물을 실제 높이만큼 세우고, 실제 표고(DEM)로 지형의 오르막·내리막을
    그대로 재현합니다. 그 위에 **3인칭 캐릭터**(three.js)가 서서 진행 방향을 보고 걷습니다.

## 쓰는 데이터 (전부 무료 · API 키 없음)

| 용도 | 서비스 |
| --- | --- |
| 지도 벡터 타일 (건물/도로) | [OpenFreeMap](https://openfreemap.org/) · OpenMapTiles 스키마 |
| 지형 고도 (3D 지형 · 경사 프로필) | [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) terrarium |
| 장소 검색 / 역지오코딩 | [Photon](https://photon.komoot.io/) · 폴백 [Nominatim](https://nominatim.openstreetmap.org/) |
| 도보 · 자전거 · 자동차 경로 | [FOSSGIS OSRM](https://routing.openstreetmap.de/) |
| 대중교통 경로 (1순위) | [Transitous / MOTIS](https://transitous.org/) — 한국은 국가교통DB(KTDB) GTFS |
| 대중교통 경로 (폴백) | OpenStreetMap 노선 관계 + 자체 RAPTOR 축소판 (Overpass) |

### 데이터에 대해 정직하게

- 버스 소요시간은 **Transitous 가 있으면 실제 시각표**, 없으면 평균 속도 **추정치**입니다.
  화면 아래에 어느 쪽인지 항상 표시합니다. 실시간 지연은 반영되지 않습니다.
- 고도(terrarium)의 원본은 SRTM 계열이라 **지표면이 아니라 표면**입니다. 고층빌딩이 언덕으로
  찍히기 때문에, 구간 최솟값으로 하부 포락선을 잡아 건물에 얹힌 표본을 걸러낸 뒤 지면 곡선을
  만듭니다 (`src/services/elevation.ts` 의 `toGround`). 남산 오르막 +217m 같은 실제 지형은
  그대로 남고, 강남 테헤란로가 129m 언덕으로 나오는 현상은 사라집니다.

## 개발

```bash
npm install
npm run dev
```

- `npm run build` — 프로덕션 빌드. maplibre-gl v6 는 렌더 워커를 `import.meta.url` 기준
  상대 경로로 찾기 때문에, 빌드 시 `dist/mlgl/` 로 워커와 공용 청크를 따로 복사하고
  `setWorkerUrl` 로 가리킵니다 (`vite.config.ts`). 이걸 안 하면 워커가 404 나면서 지도가
  통째로 멈춥니다.
- `?rafshim` — 개발 서버 전용. 탭이 백그라운드일 때도 렌더 루프를 돌립니다.
  자동화 브라우저로 지도를 스크린샷 검증할 때만 씁니다. 빌드 산출물에는 들어가지 않습니다.
- dev 빌드에는 왼쪽 아래에 **주행 시뮬레이터**가 뜹니다. 실제로 걷거나 버스를 타지 않고도
  계획된 경로를 따라 가짜 GPS 를 흘려보내 단계 전환과 3D 카메라 추적을 확인할 수 있습니다.

## 구조

```
src/
  App.tsx              화면 셸 — 헤더 / 이동수단 세그먼트 / 입력 / 지도 / 결과 패널
  types.ts             공용 타입
  lib/geo.ts           거리·방위·폴리라인 유틸
  services/
    geocode.ts         장소 검색, 역지오코딩
    geolocation.ts     GPS 구독 + 시뮬레이션 주입
    routing.ts         OSRM 도보/자전거/자동차 + 한국어 안내문 변환
    motis.ts           Transitous(MOTIS) 대중교통 — 시각표 기반
    transitOsm.ts      OSM 노선 관계 기반 폴백 엔진 (RAPTOR 축소판)
    transit.ts         두 엔진을 묶는 오케스트레이터
    elevation.ts       terrarium DEM 샘플러 + 지면 고도 추정 + 경사 색
  map/
    style.ts           회색 팔레트 지도 스타일 (2D/3D 공용)
    MapView.tsx        지도 · 경로/정류장 레이어 · 카메라
    CharacterLayer.ts  three.js 3인칭 캐릭터 커스텀 레이어
  state/store.ts       zustand 스토어 — 경로 계획, 안내 진행 상태
  ui/                  입력 필드, 결과 패널, 고도 그래프, 아이콘, 시뮬레이터
```

## 아이폰에 설치

1. 같은 네트워크에서 `npm run dev -- --host` 로 띄우거나 빌드본을 HTTPS 로 배포합니다.
   (GPS 는 `localhost` 이거나 HTTPS 여야 동작합니다.)
2. 사파리로 접속 → 공유 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 열면 상태바까지 쓰는 전체화면 앱으로 뜹니다.
